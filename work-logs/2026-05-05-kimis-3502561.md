## 작업 요약

PC-6에서 manifest + SW를 도입했지만 사용자가 install 진입점을 직관적으로 인지하기 어려웠던 문제를 해결. `BeforeInstallPromptEvent`를 가로채 헤더에 펄스 애니메이션 다운로드 아이콘 버튼을 노출, 클릭 시 직접 `prompt()` 호출하도록 했고 iOS Safari는 자동 prompt 미지원이라 "공유 시트 → 홈 화면에 추가" 안내 모달을 분리 제공. 이미 standalone 또는 설치 완료 시 버튼 자동 숨김.

## 변경된 파일

- `src/components/layout/PwaInstallButton.tsx` (신규)
  - `beforeinstallprompt` 이벤트 가로채 deferred prompt 상태 저장
  - 클릭 시 `prompt()` + `userChoice` 처리, accepted 시 `setInstalled(true)`
  - `display-mode: standalone` / iOS `navigator.standalone` 가드로 설치된 환경에선 자동 숨김
  - `appinstalled` 이벤트 리스너로 설치 완료 후 즉시 숨김
  - iOS Safari 분기 — 자동 prompt 미지원 → 공유 시트 3단계 안내 모달
- `src/components/layout/Header.tsx` — 음악/알림 버튼 옆에 `<PwaInstallButton />` 마운트
- `src/app/globals.css` — `.pc-install-btn` (primary tint + amber border) + `pc-install-pulse` 키프레임(2.4s 무한 펄스)
