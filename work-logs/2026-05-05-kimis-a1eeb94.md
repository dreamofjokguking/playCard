## 작업 요약

평가 결과 등록 후 잘못된 점수를 수정할 방법이 없고 누가 언제 무엇을 바꿨는지 이력도 남지 않던 운영 공백을 해소. `Evaluation` 모델에 `editLog` 배열(이전 ratings/mvpPick 스냅샷 + editor/editedAt/reason)을 추가하고, 어드민/클럽 관리자가 호출하는 `PATCH /api/admin/evaluations/[id]`(reason 필수)와 매치별 평가 목록 GET 엔드포인트를 신설. 점수 수정 시 `Match.results`를 재계산해 결과 페이지/순위가 즉시 따라오도록 하되, 기존에 부여된 칭호(`title`/`rarity`)는 prevByUser 머지로 보존해 수정 한 번으로 칭호가 사라지는 사고를 막음. 어드민 매치 상세 페이지(`/club-rooms/[id]/admin/matches/[matchId]`)는 평가자별 카드 + 수정 가능 점수 셀 + MVP 셀렉트 + 사유 입력 + 수정 이력 패널 구조. POST 핸들러의 `aggregateResults` inline 로직은 `src/lib/matchAggregation.ts`로 추출해 PATCH와 공유.
