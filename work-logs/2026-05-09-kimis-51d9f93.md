## 건드리면 안 되는 부분

| 파일 | 위치 | 이유 |
| ---- | ---- | ---- |
| `src/components/layout/BottomNav.tsx`, `SideNav.tsx` | `bestMatchHref` (가장 긴 prefix가 우승) | 단순 `startsWith(item.href + '/')`로 되돌리면 홈 href가 모든 서브 경로의 prefix라서 클럽 내부 어디를 가도 홈이 활성됨. items 전체에서 길이순 정렬 후 1등을 뽑는 패턴이 핵심 |
| `src/app/globals.css` | `body { overflow-x: hidden }` | 모든 모바일 overflow의 최후 안전망. 풀면 어떤 자식이든 가로로 새는 순간 뷰포트 가로 스크롤이 발생. 풀고 싶다면 자식들 각각의 `min-width: 0` / `overflow-wrap` 보강이 선행되어야 함 |
| `src/app/globals.css` | `.card`, `.quick-link` `overflow-wrap: anywhere; word-break: break-word; min-width: 0` | 긴 닉네임/ID/공백 없는 영문 텍스트가 카드 폭을 초과하지 않도록 강제 줄바꿈. `min-width: 0`이 없으면 grid/flex 부모의 자식 본질상 최소 폭이 콘텐츠 크기로 잡혀 부모를 밀어냄 |
| `src/app/globals.css` | `.pc-flex-between > * { min-width: 0; max-width: 100% }` | flex 자식이 자체 콘텐츠 크기로 부모를 늘리지 못하도록. 단순 `flex-wrap: wrap`만으로는 wrap이 안 되는 케이스(자식이 강제로 넓이를 가질 때) 대응 불가 |
| `.github/workflows/keepalive.yml` | cron 두 조각 (`*/13 21-23 * * *` + `*/13 0-14 * * *`) | KST 06–24시 동작. UTC 21–23 + 0–14 두 조각으로 자정 가로지르기 표현. 한 줄로 합치면 시간대 잘림. 또한 13분 주기 = Render Free 15분 슬립 임계 직전 — 14분 이상으로 늘리면 슬립 발생 가능 |
