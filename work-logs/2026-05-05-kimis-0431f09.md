## 건드리면 안 되는 부분

| 파일 | 위치 | 이유 |
| ---- | ---- | ---- |
| `src/lib/models/User.ts` | `kakaoId` / `googleId` `partialFilterExpression { $type: 'string' }` | sparse만으로는 `kakaoId: null` 두 개 doc 충돌 발생. `$type: 'string'` 조건 = "값이 문자열일 때만 unique"가 핵심. 단순 sparse로 되돌리면 두 번째 구글 가입자에서 즉시 500 발생 |
| `src/app/api/auth/{kakao,google}/callback/route.ts` | `needsOnboarding = !existing.onboardedAt` 분기 | 신규 가입자만 `/onboarding`으로 보내고 기존은 그대로 `/` 진입. 이 가드 빼면 매 로그인마다 온보딩으로 떨어짐 |
| `src/app/api/club-rooms/route.ts` | `User.findByIdAndUpdate(ownerId, { role: 'admin', clubRoomId, onboardedAt })` | 신규 OAuth 가입자가 클럽을 만든 직후 'pending'으로 남는 사고를 막는 핵심. clubRoomId 자동 설정도 `getActorAccess`/`isMember` 판정과 직결 |
| `src/app/api/auth/me/route.ts` | role pending → admin self-heal | 클럽 owner인데 role이 pending인 기존 사용자도 자동 보정. 이 분기 빼면 위 fix 이전에 만들어진 사용자들이 영구히 pending으로 남음 |
| `src/app/club-rooms/search/page.tsx` | "가입 신청" 버튼의 `event.preventDefault() + stopPropagation()` | 카드 자체가 `<Link>`로 감싸져 있음. 이 두 줄 빼면 가입 신청 클릭 시 카드 링크가 우선 작동해 `/about`으로 빠짐 |
| `src/app/api/upload/image/route.ts` | `MAX_BYTES` / `ALLOWED_MIME` 검증 | Cloudinary는 무료 플랜이라 무제한 업로드 시 즉시 한도 소진. 클라이언트도 검증하지만 서버 사이드 가드가 진짜 안전선 |
| `src/app/globals.css` | `:root { color-scheme: only dark }` + `.pc-field { color-scheme: dark; -webkit-text-fill-color }` | Android Chrome Auto Dark Theme이 폼/배경을 임의로 반전시키는 문제 차단. `only` 키워드와 `-webkit-text-fill-color` 둘 다 필수 |
