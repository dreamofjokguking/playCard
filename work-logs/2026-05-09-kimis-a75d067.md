## 건드리면 안 되는 부분

| 파일 | 위치 | 이유 |
| ---- | ---- | ---- |
| `src/components/layout/Header.tsx` | `signOut`의 `router.replace + router.refresh` 순서 | `replace` 후 `refresh`로 서버 컴포넌트(SideNav 등) 재실행 → me 세션 캐시 클리어. 순서 바뀌거나 refresh 빠지면 로그아웃 후에도 일부 영역에 옛 me 데이터가 남음 |
| `src/components/layout/Header.tsx` | `signingOut` 가드 (`if (signingOut) return`) | 더블 클릭 시 DELETE 두 번 + replace 두 번으로 깜빡임 발생. 가드 제거 시 사용자 환경에서 1초 안에 두 번 클릭하면 재현 |
| `src/app/club-rooms/page.tsx` | `redirect('/club-rooms/search')` | server-side redirect. 이 파일을 client component로 바꾸면 server redirect가 동작하지 않아 옛 테스트 페이지가 다시 노출 위험 |
| `src/app/error.tsx` | `'use client'` 지시자 | Next.js Error Boundary 규약상 client component만 가능. server component로 전환 불가 |
