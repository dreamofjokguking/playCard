## 작업 요약

기획서 Phase 8.3(YouTube 연동)을 외부 API quota/인증 없이 RSS Atom 피드 방식으로 구현. `ClubRoom.youtubeChannelId` 필드 추가, 어드민 페이지에서 channel_id 등록, 클럽 메인에 최신 영상 4개 카드 그리드 자동 노출. RSS 파싱은 정규식 기반(외부 라이브러리 의존성 0), Next.js fetch `revalidate: 600`로 10분 서버 캐시 — YouTube 측 부하/우리 cold path 모두 최소화. 채널 미등록이면 섹션 자체 비노출.
