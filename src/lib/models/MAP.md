# Mongoose 모델 MAP (PlayCard Bootstrap)

## 현재 상태

- `src/lib/models` 하위 실제 모델 파일은 아직 없음.
- 기획서 기준 최소 모델 인덱스를 먼저 정의.

## 1차 모델(예정)

- `User.ts`
- `ClubRoom.ts`
- `Match.ts`
- `Evaluation.ts`
- `BGMTrack.ts`

- 상세 스키마는 `docs/plans/playcard 통합 구축 플랫폼 — 개발 지시서.md` 기준
