# PlayCard 디자인 시스템

> 동호회 통합 운영 플랫폼 · 스포츠 게임 인터페이스
>
> *"오늘의 경기를 카드 한 장으로 — 평가하고, 분석하고, 등급 매기고."*

---

## 브랜드 컨텍스트

**PlayCard**는 족구 동호회의 경기 기록·동료 평가·순위·자동 팀 구성을 통합 운영하는 모바일 메인 플랫폼입니다. FIFA/NBA 카드 게임에서 영감을 받아, 동호회 활동을 **시즌·선수카드·능력치 차트·MVP 시상**으로 재해석합니다.

> **확장성 메모**
> 현재 1차 타깃은 족구지만, 시스템은 모든 라켓·구기 종목으로 확장 가능하도록 설계되어 있습니다.
> 포지션 정의(공격/수비/토스/서브)는 종목별 설정값일 뿐, 컴포넌트 자체는 종목 비종속입니다.
> 향후 `sport: "jokgu" | "tennis" | "badminton" | ...` 토큰으로 분기되도록 디자인 토큰을 구성합니다.

### 핵심 가치
1. **가볍고 친근하게** — 진지한 평가가 무거운 짐이 되지 않도록. 게임 시스템 톤("경험치 +120!", "레벨업!")으로 평가 행위 자체를 재미로 전환.
2. **선수 카드 메타포** — 모든 회원은 카드 한 장. 능력치, 칭호, 사진, 등급(레어리티)이 한눈에.
3. **확장 가능한 토큰** — 종목/시즌/테마가 바뀌어도 코어 토큰은 그대로.

## CONTENT FUNDAMENTALS — 톤 & 카피라이팅

### 핵심 톤
**게임 시스템 톤** — 친근하고 가볍지만, 약간의 호들갑과 위트가 섞인 톤. 평가 행위가 부담스럽지 않도록 시스템 메시지로 분산시킵니다.

| 구분 | 사용 |
|---|---|
| 인칭 | 사용자에게 **"~님"** (정중) — 그러나 시스템 메시지는 반말/명사형으로 가볍게 |
| 어미 | 안내문은 정중체("~하세요"), 시스템 알림은 명사형("레벨업!", "경험치 획득") |
| 이모지 | 최소 사용. 시스템 액션·축하 시 1개씩만 (🎉 ⚡️ 🏆). 대신 등급 색상·뱃지·아이콘으로 표현. |
| 영어 | 시스템 용어는 영어 OK ("MVP", "POTM", "LV.12", "EXP +120"). 일상 문장은 한글. |

### 톤 예시 (Do / Don't)

| 상황 | ✅ | ❌ |
|---|---|---|
| 평가 마감 알림 | "오늘 경기 평가 마감!\n참여자 7명 모두 제출 완료 🎉" | "평가가 종료되었습니다. 모든 참여자가 평가를 완료하였습니다." |
| 칭호 부여 | "새 칭호 획득!\n**「네트 위의 암살자」**\n\n+EXP 120" | "회원님께 새로운 칭호가 부여되었습니다." |
| 빈 상태 | "아직 경기가 없어요\n첫 경기를 만들어볼까요?" | "데이터가 존재하지 않습니다." |
| 미승인 사용자 | "관리자 승인 대기 중\n잠시만 기다려주세요 ⏳" | "귀하의 가입 신청이 검토 중입니다." |
| 에러 | "잠시 끊겼어요\n다시 시도해주세요" | "Internal Server Error 발생" |

### 카피 패턴
- **숫자에 단위를** — "12경기" "평균 7.4점" "MVP 3회"
- **동사로 끝내기** — 버튼은 "평가하기", "팀 짜기", "내 카드 보기"
- **비교/순위는 가볍게** — "저번보다 ▲0.3점!" "당신은 상위 24%"
- **AI 칭호는 위트 있게** — 부진해도 비하하지 않고 비유. "오늘의 안전제일주의자", "벤치의 황태자"

### 금지
- 비하·부정적 단어 ("못함", "꼴찌", "실패")
- 진지·관료적 어투 ("귀하", "안내드립니다", "검토 중에 있습니다")
- 과한 이모지 도배
- 영어 마케팅 카피체 ("Awesome!", "Great job!")

## VISUAL FOUNDATIONS — 비주얼 파운데이션

### 색상 (Color)
- **Primary**: 족구 오렌지 `#FF5C39` — 경기, 행동, 강조
- **Secondary**: 코트 그린 `#1E9E5C` — 성공, 완료, 출석
- **Accent**: 골드 `#F4B740` — MVP, 레전더리 칭호, 시상
- **Surface**: 따뜻한 화이트 `#FFFBF5` — 페이퍼 같은 배경
- **Background**: 크림 `#FAF6EE` — 메인 배경, 따뜻한 톤
- **Ink (Text)**: `#1A1410` (warm black) — 순수 검정 대신 온기 있는 다크 브라운
- **Rarity Spectrum** (등급/희귀도):
  - Common 일반: `#9CA3AF` (회색)
  - Rare 희귀: `#3B82F6` (파랑)
  - Epic 영웅: `#A855F7` (보라)
  - Legendary 전설: `#F4B740` + 그라디언트 (골드)

> 무드: **따뜻한 페이퍼 + 활기찬 그라디언트**. 다크/네온 아님. 코트 위 햇살 같은 따뜻함.

### 타이포그래피
- **본문/UI**: Pretendard Variable — 한국어 가독성 최강, 토스/카카오톡과 같은 모던한 인상
- **숫자/스탯**: Pretendard `font-feature-settings: "tnum"` (Tabular Numbers) — 점수·순위 정렬용
- **디스플레이/스코어**: Pretendard 900 + 살짝 italic (`-3deg skew`) — 스포츠 점수판 느낌
- **모노**: JetBrains Mono — 코드, ID, 시스템 메시지

> 영문 디스플레이가 필요할 때만 별도 폰트. 본문은 일관되게 Pretendard.

### 스페이싱 (Spacing)
4px 기반 8단계 스케일: `2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`. CSS 변수 `--space-{n}`.

### 코너 라디우스
- 작은 요소 (badge, button-sm): `8px`
- 중간 (button, input, card): `14px`
- 큰 카드 (선수카드, MVP카드): `20px`
- 시트/모달: `24px` (top corners only)
- 풀 라운드: `9999px` (avatar, pill)

### 그림자 / 엘리베이션
- `--shadow-sm`: `0 1px 2px rgba(26,20,16,.06)` — 입력 필드, 작은 칩
- `--shadow-md`: `0 4px 14px -2px rgba(26,20,16,.10)` — 카드 기본
- `--shadow-lg`: `0 12px 32px -8px rgba(26,20,16,.18)` — 떠 있는 카드, 모달
- `--shadow-glow-gold`: `0 0 24px rgba(244,183,64,.45)` — 레전더리 칭호, MVP

색상은 **순수 검정 대신 잉크색 알파(`rgba(26,20,16,...)`)** — 따뜻한 톤 유지.

### 배경 / 텍스처
- 메인 배경: 단색 크림 `#FAF6EE`
- 옵션 액센트: 매우 옅은 코트 라인 (베이지 위 `#E8DFC8` 1px line)
- 풀블리드 이미지: 거의 사용 안 함. **카드 단위 비주얼**이 메인.
- 그라디언트: 등급 카드 배경(레전더리 골드 그라디언트), MVP 시상대 정도. 메인 UI는 솔리드.

### 애니메이션
- **이징**: `cubic-bezier(0.34, 1.56, 0.64, 1)` (overshoot, 살짝 통통) — 핵심 인터랙션
  - 표준 트랜지션은 `cubic-bezier(0.4, 0, 0.2, 1)` (Material standard)
- **시간**: 빠른 마이크로(120ms), 표준(200ms), 강조(320ms), 칭호 부여(800ms+)
- **카드 등장**: 살짝 위로 떠올라 페이드인 (translateY 8px → 0, fade)
- **점수 변동**: 숫자 카운트업 (300ms)
- **레벨업/칭호**: 폭죽, 빛 번짐, 스케일 펄스
- **호버**: 카드 살짝 띄움 (translateY -2px + shadow 강화)
- **프레스**: 0.96 스케일 + 0.96 opacity, 80ms

### 보더
- 카드: `1px solid #EFE7D6` (cream-darker) — 너무 얇지도 두껍지도 않게
- 강조: `2px solid` primary
- 입력 포커스: `2px solid #FF5C39 + outline-offset: 2px`

### 카드 아나토미
- 일반 카드: 라디우스 14px, 보더 1px cream, shadow-md
- 선수 카드: 라디우스 20px, **등급별 보더 그라디언트 1.5px**, shadow-md → hover시 lg
- MVP 카드: shadow-glow-gold + 골드 그라디언트 배경
- 모달/시트: 라디우스 24px (top), shadow-lg, 백드롭 blur(8px)

### 투명도 / 블러
- 글래스 보호 그라디언트는 **사용 안 함** (페이퍼 컨셉에 맞지 않음)
- 모달 백드롭만 blur(8px) + rgba(26,20,16,0.4)
- 비활성 상태: opacity 0.4

### 호버 / 프레스 상태
- 호버: shadow 한 단계 + translateY -2px + 보더 강조 (cream → primary 30%)
- 프레스: scale 0.96 + opacity 0.96, 80ms
- 활성: primary tint 배경 (FF5C39 8%)
- 포커스: 2px primary outline + 2px offset

### 레이아웃 규칙
- 모바일: 풀폭 패딩 16px, 카드 사이 12px gap
- 데스크톱: max-width 960px 중앙. 좌측 사이드바 248px.
- 하단 네비게이션 안전영역: 모바일 64px + safe-area-inset-bottom

## ICONOGRAPHY — 아이콘

### 사용 원칙
- 모든 아이콘은 stroke 1.75 (Lucide 기본보다 살짝 두껍게)
- 24px 그리드 표준. 작은 곳은 16px, 큰 곳(빈 상태)은 48px.
- 색은 currentColor — 컨텍스트 따라 자동
- **이모지는 시스템 알림에서만** 1개씩 (🎉 🏆 ⚡️ 🥇 ⏳)
