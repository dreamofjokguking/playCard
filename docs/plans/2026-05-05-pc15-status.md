### 기존 API 수정

- `GET /api/auth/me` — `nickname` / `profileImage` / `onboardedAt` / `needsOnboarding` 추가 + 클럽 owner인데 role이 pending이면 자동 admin 승격
- `POST /api/club-rooms` — `category` / `description` / `coverImage` 받음 + 생성한 owner의 role을 자동 admin 승격, clubRoomId 자동 설정, onboardedAt 보강
- 카카오/구글 OAuth 콜백 — 신규 가입자는 `/onboarding`으로 리다이렉트, 기존 사용자는 `/`

### 신규 페이지 (3개)

- `/onboarding` — 2단계 (닉네임 확정 → 첫 클럽 합류/생성)
- `/club-rooms/[id]/about` — 공개 클럽 소개 (커버, 카테고리, 소개 + 가입 신청. 평가/순위 비노출)
- `/club-rooms/[id]/admin/positions` — 평가 항목(공격/수비/토스 등) 관리. 프리셋 16종 + 커스텀 추가, 순서 ↑↓, 활성/비활성 토글

### 기존 페이지 수정

- 클럽 생성 (`/club-rooms/new`): 카테고리 자유 입력 → **고정 select 19종**(축구/풋살/야구/배구/농구/족구/테니스/배드민턴/탁구/골프/볼링/당구/등산/자전거/러닝/수영/클라이밍/댄스/기타). 클럽 소개 textarea (500자) + 커버 이미지 업로드
- 클럽 검색 (`/club-rooms/search`): 카드 그리드 + 카테고리 필터 + "둘러보기" 버튼 제거, **카드 클릭 시 `/about` 공개 페이지로 이동**, 가입 상태별 버튼 분기

- 헤더: 로그인 ↔ 로그아웃 자동 분기, 클럽 칩/활성 페이지 라벨 제거, 로고 그라디언트 강화 (24px + Primary→Secondary 그라디언트)
- 로그인 페이지: 옛 dev 세션 강제설정 도구 제거

### 운영/품질

- **다크모드 일관성**: `color-scheme: only dark` + `forced-color-adjust: none` + Next.js Viewport `colorScheme: 'dark'` + 폼 요소 `-webkit-text-fill-color`/`appearance` 보강. Android Chrome Auto Dark Theme이 일부 요소를 임의 반전시키던 문제 해결
- **Cloudinary 업로드**: 기존 `src/lib/cloudinary.ts` 헬퍼 재활용, 이미지 검증 + 폴더 분리 (`playcard/club-cover` 등)
- **Dev 시드 호환**: 시드 사용자는 자동으로 `onboardedAt` 세팅되어 온보딩 우회

### 운영 중 발생/해결한 이슈

- **카카오 OAuth `redirect_uri_mismatch`** → `.env.local`의 `NEXT_PUBLIC_APP_URL=http://localhost:300` 오타(`:3000` 아님). 수정 후 해결
- **카카오 OAuth `invalid_client`** → `KAKAO_CLIENT_SECRET`이 콘솔에서는 활성화돼 있는데 env에는 없었음. env에 secret 추가 후 해결
- **구글 OAuth 두 번째 가입자 500 에러** (`E11000 dup key { kakaoId: null }`) → 이전 스키마(`kakaoId: required + unique`)일 때 만들어진 비-sparse unique 인덱스가 DB에 그대로 남아있었음. `/api/dev/sync-user-indexes`로 partialFilterExpression unique로 교체 → 해결
